## Rounding and 2015 Analysis

Across 2013, 2014, 2016, 2019, 2020, and 2021, the raw survey weights produce fractional values that round to the exact integers in the target paste:
- 2013: `46,307.54` -> `46,308`
- 2014: `32,212.34` -> `32,212`
- 2016: `36,227.25` -> `36,227`
- 2019: `35,039.81` -> `35,040`
- 2020: `38,827.24` -> `38,827`
- 2021: `37,841.95` -> `37,842`

In 2017 and 2018, the official tables report the values pre-rounded to whole integers (`40,810` and `36,313`), identically matching the paste.

In 2015, the provincial statistical table provides `35,084.0`, whereas the target paste records `35,083`. This represents a single-unit discrepancy resulting from unrounded sample weight aggregation (sum of microdata survey weights before provincial round-off vs. post-aggregation integer summation).
